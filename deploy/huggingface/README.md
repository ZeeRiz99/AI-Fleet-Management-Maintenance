# AI Fleet Management & Maintenance

Live demo of a predictive-maintenance dashboard for a (simulated) Pakistani fleet: 30-day breakdown risk with SHAP
reasons, fuel-anomaly detection, rupee cost impact, and a Roman Urdu / English assistant.

- Source code: https://github.com/ZeeRiz99/AI-Fleet-Management-Maintenance
- The fleet data is **simulated** (modelled on the mindweave sample, CC-BY-NC 4.0, plus MIT engine-sensor readings),
  so results show the method, not real-fleet accuracy. Non-commercial use only.
- The assistant works offline by default. To try the Gemini/Claude mode, paste your own key in the sidebar; it is kept
  only in your browser session.
